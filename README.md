# Backend Engineering

An engineering-first backend development curriculum focused on building production-ready backend systems through independent problem solving.
---
# Goal

By the end of this roadmap, I should be able to independently:

* Design backend architectures
* Build REST APIs
* Model relational databases
* Implement authentication and authorization
* Debug backend applications
* Write automated tests
* Dockerize services
* Understand the reasoning behind every engineering decision
